# API управления космическим флотом

## Общие возможности API 
Формат данных: Обмен данными между клиентом и сервером осуществляется в формате JSON. 
Персистентность: Все изменения (добавление, удаление, редактирование) автоматически сохраняются в локальные JSON-файлы (members.json, starships.json, missions.json). При запуске приложения данные загружаются из этих файлов, восстанавливая последнее состояние системы. Идентификаторы: Каждый ресурс (член экипажа, корабль, миссия) имеет уникальный идентификатор (member_id, spaceship_id, mission_id), который используется для поиска и связывания сущностей. Обработка ошибок: Реализован глобальный обработчик ошибок 404, возвращающий стандартный JSON-ответ {"error": "Resource not found"} при обращении к несуществующим маршрутам. Связи сущностей: Члены экипажа могут быть закреплены за кораблями. Корабли могут быть назначены на выполнение миссий. При удалении члена экипажа он автоматически исключается из списков экипажей всех кораблей. Кодировки: При сохранении данных используется ensure_ascii=False для корректного отображения кириллицы в JSON-файлах.

# Управление членами экипажа

## Возвращает список всех членов экипажа в виде массива JSON-объектов. 
GET /members/list

## Добавляет нового члена экипажа. 
POST /members/add 
Тело запроса (JSON): 
json { "name": "Имя члена экипажа", "role": "Роль" } 
Создает объект CrewMember и сохраняет обновленный список в members.json.

## Удаляет члена экипажа по его ID. 
POST / GET /members/delete/int:member_id 
При удалении автоматически исключает ID этого члена из списков members всех кораблей, на которых он числился. 

## Возвращает подробную информацию о члене экипажа. Если член закреплен за кораблем, в ответ добавляется поле ship с названием корабля.
GET /member/view/int:member_id 

# Управление кораблями

## Эндпоинты для работы с космическими кораблями.

## Возвращает список всех кораблей флота. 
GET /ship/list/

## Добавляет новый корабль. 
POST /ship/add/ 
Тело запроса (JSON): json { "name": "Название корабля", "type": "Тип корабля" }

## Создает объект Spaceship и сохраняет обновленный список в starships.json. 
POST / GET /ship/delete/int:id 
Удаляет корабль по его ID.

## Назначает члена экипажа на корабль. 
POST /ship/addmember/ 
Тело запроса (JSON): json { "spaceship_id": 1, "member_id": 1 } 
Выполняет проверку: если член экипажа уже числится на другом корабле, API вернет ошибку.

## Изменяет статус корабля (например, в простое, на миссии). Старое и новое значения статуса возвращаются в ответе. 
POST / GET /ship/change_status/int:spaceship_id/string:status

## Возвращает подробную информацию о корабле. 
GET /ship/view/int:spaceship_id

# Управление миссиями

## Эндпоинты для планирования и контроля операций флота.

## Возвращает список всех активных и завершенных миссий. 
GET /missions/list

## Создает новую миссию. 
POST /missions/add 
Тело запроса (JSON): 
json { "name": "Название миссии", "goal": "Цель миссии" } 
Создает объект Mission и сохраняет обновленный список в missions.json.

## Удаляет миссию по ID. 
POST / GET /missions/delete/int:mission_id 
В ответе возвращается объект удаленной миссии, в котором поле status принудительно меняется на удалена.

## Назначает корабль на выполнение миссии. 
POST /missions/add_ship 
Тело запроса (JSON): json { "mission_id": 1, "spaceship_id": 1 } 
Добавляет spaceship_id в массив spaceships внутри объекта миссии.
